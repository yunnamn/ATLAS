# Research engine threat model

This is a single-user local development application, not a public autonomous browsing service. External research tools read sources; they cannot submit applications, send messages, purchase anything, execute arbitrary commands, or modify external accounts. The model API itself requires explicit enablement and per-run consent because it may cost money and receives source excerpts.

| Threat | Enforced boundary | Remaining limits |
| --- | --- | --- |
| Source/search prompt injection | Untrusted content is a user-data payload, never a system message. Typed model outputs, actual candidate IDs, exact domains and independent tool budgets govern dispatch. No shell/filesystem/email tools exist. | A model may still misinterpret content or choose poor permitted actions; policy is enforced independently and semantic quality is not guaranteed. |
| SSRF / DNS rebinding | HTTP(S) only, exact IDNA-normalized domain scope, no IP literals/userinfo/nonstandard ports/sensitive query names, no traversal/control-character paths. Resolve A/AAAA with no search suffix; reject any non-public/mixed/private or transition-tunnel answers. Connect to a validated IP without re-resolving the host; retain original TLS SNI/Host and certificate verification. | Direct public egress is required. Proxy-only environments fail closed; no unpinned proxy fallback is provided. Approved public hosts themselves may serve misleading content. |
| Redirect abuse | At most three redirects; validate each destination before requesting it; check robots on every destination host. Cached redirect destinations must still belong to the current run scope. | Site policies can change between requests; no paid access, CAPTCHA bypass, login automation or authentication escalation is implemented. |
| Uncontrolled scraping / access restrictions | Explicit user seeds and at most eight domains; no general crawler. Robots is fail-closed on denied/unavailable policy, with 404 treated as absent; honor declared crawl delay/request rate, a minimum one-second interval by default, and run/network/tool limits. 401/403/429 are not bypassed. | Robots is a machine-readable signal, not proof of legal permission. Rate coordination is per run/one local worker; do not run multiple worker processes or replicas. |
| Oversized / malicious documents | 2-MiB source downloads, identity encoding requested and compressed responses rejected, bounded network timeouts, 100,000-character normalized text cap. PDF parsing runs in a fixed subprocess with a 12-second wall timeout, 8 CPU seconds, 512-MiB address-space, 30-page cap; encrypted/scanned/unreadable PDFs are rejected. HTML strips scripts/forms/styles/templates and uses a non-executing parser. | HTML parsing is byte-bounded but not an OS sandbox. Add container isolation, concurrent request limits and malware/content controls before public hosting. No OCR. |
| Fabricated citations / scope confusion | Exact support and scope spans must resolve to saved normalized text and raw document version hash. Value must occur in the quote. Basic omitted-negation/qualifier checks reject misleading fragments. Unsupported candidates are excluded from report findings. | Mechanical matching cannot prove semantic entailment, completeness, source authenticity, or applicant-specific applicability. Dates/awards/tracks and complex conditions need human review. |
| False independence / consensus | Corroboration needs two distinct content hashes and explicit caller-declared independent authority groups; LLM agreement or two URLs never suffices. Conflicting supported values remain visible with both citations. | Caller authority assertions may be wrong; mirrored or coordinated content can remain correlated. Corroboration is qualified, not independent certification. |
| Secret exfiltration | Secrets exist only in trusted model/search configuration; source requests never inherit ambient proxy credentials, model auth, or arbitrary headers. No credential values in API capability data, prompts, run requests, events or reports. Provider errors are sanitized; raw response/reasoning fields are not stored. LangSmith tracing is explicitly disabled. | Source excerpts/objectives are sent to the explicitly configured live provider. Users must approve its data handling and store credentials securely. Local DB/source snapshots may contain user research data; protect and back them up accordingly. |
| Budget exhaustion / looping | Bounded conditional graph, request/token reservations including retries, model timeout/retry caps, document/window/candidate caps, cooperative time/cancellation checks and partial-report finalization. Invalid tool selections consume decision/model budget. | Cancellation is cooperative. Blocking network/DNS/parser operations can finish after the elapsed deadline but remain separately bounded; there is no unsafe thread termination. No guarantee of an instant cancel. |
| Process crash / duplicate spend | Persist plans/events/artifacts and application-level node-boundary snapshots. Mark interrupted runs failed; never replay model requests automatically. | No durable external queue, lease, LangGraph persistent checkpointer, automatic resume or multi-process execution support. |
| Stored XSS / UI rendering | React escapes excerpts, objectives and provider data. Source HTML/PDF is never embedded or executed; saved text is shown in a native modal/preformatted text. HTTP(S) links use noreferrer. | No authentication/authorization or tenant isolation. Bind to loopback and do not publish this as a public service without separate hardening. |

Offline security tests simulate malicious source instructions, attempted metadata fetches, private/mixed DNS responses, unsafe URLs/redirects, denied robots paths, limits, fabricated quotation spans, dropped negation, schema-invalid model tools and cancellation/failure. They establish application-boundary behavior; they do not certify that a real model ignores every prompt injection or that an untested live network is reachable.
